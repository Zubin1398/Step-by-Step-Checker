# 🛠️ [K] Stepper — модуль автоматизации проверок

Userscript для автоматизации рутинных проверок, сбора результатов и управления очередью обработки хешей. Предоставляет пошаговый и автоматический режимы, фильтрацию результатов и удобный интерфейс для работы с данными.

## 🚀 Основные возможности

- **🎯 Пошаговый режим (F2)** — полный контроль над процессом: одно действие запускает одну проверку.
- **⚡ Автоматический режим (Auto-check)** — последовательно обрабатывает список ников и продолжает работу, пока не закончится входной список.
- **📋 Очередь обработки** — управляет задачами с учётом ограничения в три активные задачи и заданного интервала между запросами.
- **🔎 Фильтрация хешей** — пропускает неподдерживаемые или нецелевые типы, включая `BCRYPT`, `NONE` и `TIGER128:SALT`.
- **📅 Фильтр по дате** — позволяет пропускать ники, уже проверенные в заданные дату и временной промежуток.
- **🧹 Очистка результатов** — собирает уникальные записи, исключает дубликаты и выводит результаты в редактируемое окно.
- **🔄 Финальный сбор (End-Sweep)** — после завершения очереди повторно сканирует таблицу, чтобы собрать результаты, которые могли появиться с задержкой при обновлении интерфейса.

## 📦 Установка

1. Установи расширение **Tampermonkey** или **Violentmonkey** для своего браузера.
2. Создай новый userscript.
3. Скопируй код из файла `[K] Stepper v5.2` и вставь его в редактор.
4. Сохрани изменения сочетанием клавиш `Ctrl + S`.
5. Открой поддерживаемую страницу сайта и проверь, появилось ли окно скрипта.

## 🎮 Как пользоваться

### 1. Подготовка списка

Открой сайт, на котором выполняются проверки, и вставь список в чёрное окно скрипта.

**Пример формата:**

```text
Ник1 | Привилегия
Ник2 | Привилегия
Ник3 | Привилегия
```

Каждая запись указывается с новой строки.

### 2. Настройка параметров

- **Auto-check** — включает автоматическую обработку списка.
- **Игнорировать старые проверки** — позволяет указать дату и время, чтобы пропускать ранее обработанные записи.

### 3. Запуск

Для пошаговой работы нажми **«Вставить следующий (F2)»** или используй клавишу `F2`.

В автоматическом режиме скрипт самостоятельно переходит к следующим записям в соответствии с заданными настройками.

## ⚙️ Как это работает

1. **Поиск и парсинг** — скрипт вставляет ник, запускает проверку и ожидает появления результатов в таблице (`fkRow`).
2. **Фильтрация** — неподходящие типы хешей исключаются из дальнейшей обработки.
3. **Управление очередью** — для поддерживаемых типов, например `SHA1`, `SHA256` и `AuthMe`, запускается обработка с учётом ограничения на количество активных задач.
4. **Ожидание результатов** — скрипт отслеживает завершение загрузки и появление результатов в интерфейсе.
5. **Финальный сбор** — выполняется повторное сканирование DOM, результаты объединяются с помощью `Set` для удаления дубликатов и выводятся в отдельное окно.
6. **Очистка интерфейса** — после завершения обработки скрипт очищает завершённые карточки, используя доступные элементы управления сайта.

## ⚠️ Важные нюансы

- **Не закрывай окно скрипта во время работы.** Если оно просто скрыто, обработка может продолжаться, но прогресс не будет виден.
- **Перемещение окна** — перетаскивай его за верхнюю часть.
- **Редактирование результатов** — в окно вывода можно добавлять собственные комментарии непосредственно во время работы.
- **Ограничения сайта** — фактическая скорость обработки зависит от доступности сайта, задержек сети и ограничений сервиса.
